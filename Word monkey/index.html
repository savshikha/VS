Standalone page

A page of its own

This site lives in its own folder at the repo root — not inside SATC. Edit the copy and styles here freely.

How to open it

The server must use the repository root as its working directory (not the SATC folder only). Then open http://localhost:8000/new-page/ — or run ./serve-dev.sh from the repo root.

SATC app with that setup: http://localhost:8000/SATC/index.html

Next steps

Rename the folder or file, change the title in <head>, and replace this content with whatever you need.

Tip: keep everything in one file for simplicity, or add a sibling styles.css in this folder if the page grows.

Independent from the SATC app — separate folder, separate entry point.
